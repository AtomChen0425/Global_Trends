## Cloudflare Computer 项目分析

Cloudflare Computer 项目旨在构建一个**虚拟文件系统**，该文件系统核心托管于 Cloudflare 的 Durable Object 中。其核心设计理念是将**权威状态**存储在 SQLite 数据库内，并通过一个**可插拔的执行环境** (`workspace.runtime`) 来暴露文件系统操作和代码执行能力。这种架构允许开发者在 Cloudflare 的 serverless 平台之上，以一种更接近传统本地开发环境的方式来构建和运行应用。

该项目提供了三种不同的执行后端，以满足不同的使用场景。**Container 后端**将 SQLite 状态映射到一个沙箱化容器内的 FUSE 文件系统，并利用 `computerd` 守护进程通过 capnweb RPC 同步状态变更，提供完整的 Linux 用户空间和网络能力。**Isolate shell 后端**则在 Dynamic Worker 中运行 `just-bash`，通过 Workers RPC 直接访问 Workspace，避免了额外的存储和同步开销。**Isolate JavaScript 后端**允许在新的 Dynamic Worker 中执行 ECMAScript 模块，支持结构化输入输出、持久化相对导入、配置库以及 Workspace 提供的 `node:fs/promises` 和受信任的 `ws:git`/`ws:artifacts` 模块。

`workspace.runtime.exec(source, { backend })` 是统一的执行入口，开发者可以通过指定后端来决定执行的是 shell 命令还是 ECMAScript 模块。所有后端都支持**惰性连接**，仅在首次使用时建立连接。此外，Workspace 也可以不配置任何后端，仅作为文件系统提供给调用者。目前该项目处于**预览阶段**，API 不稳定，不建议用于生产环境，但非常适合实验、探索和原型开发。

该项目通过引入一个轻量级的状态内核来实现其功能，该内核独立于具体的 Agent 运行时。LoopX 的实现思路是将复杂的长期工作分解为一系列可控的、有界的回合。在每个回合中，系统会根据预设的状态（包括目标、门禁、待办事项、范围、证据和配额）来决定下一步行动。这可能包括等待人类决策、执行一个 Agent 的有界切片，或者由 Codex、Claude Code、Cursor 或自定义的 shell Agent 执行一个回合。Agent 的执行结果会被记录为证据，并根据配额决定下一个回合的执行。这种模式类似于一个“Agent 原生的看板”，其中每个任务卡片都包含身份、权限、证据和延续信息，而状态的流转则通过“认领”、“门禁”、“监控”和“写回”等操作来验证。

**技术分析：基于图网络的连续时间表面演化预测模型**

**背景**
在医学影像分析领域，预测皮层下结构形状的长期演化对于疾病预后和临床试验设计至关重要。现有方法主要依赖高维嵌入进行形状轨迹外推或直接回归顶点变形，但这些方法在处理连续时间演化和任意预测时域方面存在局限性。

**技术实现**
本文提出了一种新颖的基于图网络的模型（MT-GNN），用于预测表面的内在几何形状。该模型的核心在于预测每个顶点的第一基本形式（度量张量），并以连续时间为基础。通过一个独立的图网络，模型能够处理任意因果多访视历史和任意预测时域，并结合傅里叶编码的领先时间进行条件化。预测的度量张量通过一个可微分的“尽可能刚性”（As-Rigid-As-Possible）求解器解码为表面。模型通过端到端的刚性对齐顶点误差进行训练，这种重建训练方式确保了解码后的预测是一个有效的表面，并持续优化其精度。

**应用场景**
该模型在ADNI数据集的14个皮层下结构上进行了评估，并在所有预测时域上均取得了优于现有方法的性能。与传统的测地线形状回归（DCM）和网格Transformer（TransforMesh）相比，MT-GNN在预测精度上表现出显著优势，且随着预测时域的增长，其优势愈发明显。这表明该模型在长期形状演化预测方面具有强大的潜力，可应用于疾病进展预测、治疗效果评估以及个性化医疗方案的制定。

**总结**
MT-GNN通过预测连续时间的内在几何度量，克服了现有方法的局限性，实现了更准确、更鲁棒的表面演化预测。其端到端的训练机制和“尽可能刚性”的解码方法保证了预测结果的有效性和可靠性。该技术有望在神经科学、医学影像分析等领域发挥重要作用，为临床决策和科学研究提供有力支持。

**技术分析：On-Policy Self-Distillation (OPSD) 的模态平衡优化**

**背景**
在多模态大语言模型（MLLMs）的视觉推理能力提升方面，On-Policy Self-Distillation (OPSD) 已成为一种主流的后训练技术。现有方法通常利用多样化输入源中的特权信息来指导自蒸馏过程。然而，这些设计忽略了MLLM推理中固有的“模态不平衡”问题。当文本信息在生成中占据主导地位时，模型难以充分融合其多模态输入，导致精心设计的特权信息未被充分利用，从而限制了OPSD的有效性。

**技术实现**
为了解决模态不平衡问题，研究者构建了两种“教师”模型：一种是“正向教师”，利用“Zoom-In Image”来突出视觉信息；另一种是“负向教师”，利用“Mask Image”来模拟模态不平衡。通过观察这两种教师模型在推理正确性和Token Logits上的变化，研究者发现“模态平衡”本身可以作为一种有效的特权信息。基于此发现，文章提出了OPD-V，一种视觉OPSD范式。OPD-V通过正向和负向教师实例化模态平衡信息，并引入“正向模态平衡Logits边距”（Positive Modality-Balance Logits Margins）来定义一个“模态平衡信任区域”（Modality-Balance Trust Region），从而选择用于自蒸馏的On-Policy Token。

**应用场景与总结**
OPD-V 的核心创新在于将模态平衡作为一种可量化的特权信息引入自蒸馏过程，有效解决了传统OPSD在模态不平衡场景下的性能瓶颈。实验结果表明，在6个基准测试、4种MLLM骨干模型和5种后训练方法上的验证，OPD-V 能够持续提升模型的视觉推理性能，同时降低训练成本。这一方法为优化MLLMs的模态融合能力和提升其在复杂视觉推理任务中的表现提供了新的技术路径。
