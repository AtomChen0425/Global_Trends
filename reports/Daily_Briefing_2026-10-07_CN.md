**背景**

Chrome 155 版本正式支持 JPEG XL (.jxl) 图像格式的解码。JPEG XL 作为新一代图像格式，旨在满足现代 Web 开发和摄影的需求，相比传统 JPEG 格式，它提供了 30-50% 的压缩率提升，支持无损压缩、内置 HDR，并能无损转码 JPEG。文章建议同时尝试 AVIF 和 JPEG XL，并认为 JPEG XL 在高保真、无损压缩，尤其是摄影图像或需要精细渐进式解码的场景下优势明显。

**技术实现**

为确保安全性，Chrome 团队选择使用 Rust 重写了 JPEG XL 解码器（jxl-rs）。图像解码器是浏览器中最关键且易受攻击的组件之一，历史上 C++ 等内存不安全语言实现的解码器常出现安全漏洞。Rust 的内存安全特性从根本上消除了这类风险。在性能方面，jxl-rs 利用了 Rust 的 `target_feature_11` 特性稳定后对 SIMD 指令的安全调用，并构建了 SIMD 抽象层（jxl_simd），借鉴了 C++ Highway 库的设计，实现了跨平台的高性能 SIMD 优化，同时将不安全操作限制在极少数经过严格审查的代码中。jxl-rs 的性能优化借鉴了 libjxl 的经验，并建立了性能仪表盘进行跟踪验证。

**应用场景与总结**

JPEG XL 的引入为 Web 带来了更快的速度、更丰富的视觉体验和更高的安全性。其高压缩率和无损特性使其非常适合用于摄影作品、高分辨率图像以及需要平滑渐进式加载的场景。Chrome 团队积极响应开发者反馈，通过 Interop 项目确保了 JPEG XL 在不同浏览器间的互操作性。开发者被鼓励开始使用 .jxl 格式，并积极反馈以持续改进 Web 生态。总而言之，JPEG XL 的集成是 Chrome 在图像格式领域的一次重要升级，它通过 Rust 的安全特性和精细的性能优化，为 Web 带来了更优质的图像处理能力。

**背景**

生命体内的分子，如氨基酸，普遍呈现出“手性同质性”，即只存在两种对映异构体中的一种。然而，在化学合成中，非手性反应通常会产生等量的两种对映异构体，这长期以来是化学领域的一个未解之谜。这种手性选择性的缺失，在药物研发等领域带来了挑战，因为只有一种对映异构体可能具有所需的生物活性。

**技术实现**

Kagan 和 Soai 的工作为解决这一难题提供了关键突破。Kagan 在1986年发现了一种新的化学反应调控方法，能够显著提高某一特定对映异构体的生成比例。随后，Soai 在1995年设计了第一个具有实现手性同质性潜力的化学反应，并在2003年成功实现了这一目标，即在反应中仅生成一种对映异构体。他们的研究核心在于发现并利用了“非线性效应和自催化在不对称有机合成中的应用”，从而实现了化学反应的“镜像选择性”。

**应用场景**

这些开创性的发现对于不对称有机合成领域具有深远意义，尤其是在药物分子的设计与制造中。能够高效、选择性地合成单一对映异构体，极大地提高了药物研发的效率和安全性，避免了不必要的副产物和潜在的副作用。此外，该技术也为其他需要精确控制分子手性的精细化工领域提供了重要的理论和实践指导。

**总结**

Kagan 和 Soai 的工作解决了化学界一个百年难题，即生命体如何实现手性同质性。他们通过对非线性效应和自催化在不对称合成中的深入研究，开发出了能够精确控制分子手性的化学反应。这些突破不仅深化了我们对生命起源的理解，更在现代药物研发和精细化工领域催生了重要的技术进步和应用。
