## pw-loudness-eq：PipeWire 上的 Windows 音量均衡器逆向工程与实现

**背景**

本文介绍了一个名为 `pw-loudness-eq` 的项目，该项目成功逆向工程并移植了 Windows 系统的音量均衡（Loudness Equalization）功能到 PipeWire 音频服务器上。Windows 的音量均衡功能旨在通过动态调整音频信号的增益，使得响亮和安静的部分在播放时音量水平更加一致，从而提升整体听感体验。

**技术实现**

`pw-loudness-eq` 主要包含两个核心模块：`loudness` 模块和 `limiter` 模块。`loudness` 模块负责对每个应用程序的播放流进行处理，通过插入一个 `audioconvert.filter-graph` 插件，在音量控制和混音之前应用增益调整。其算法基于一个宽带自动增益控制（AGC），通过 FFT 分析音频帧的功率谱，将其划分为 25 个频段，并根据设定的阈值计算目标增益，实现音量平滑。`limiter` 模块则模拟了 Windows 音频引擎（AudioEng.dll）的输出限制器，在所有播放设备上，混音和软件音量调整之后，对输出信号进行前瞻性限制，以防止信号过载（clipping）。该模块通过一个延迟缓冲区来预测峰值，并在线性时间内调整增益以避免失真。

**应用场景**

该项目为 Linux 用户提供了一个强大的音频增强工具，尤其适用于需要平衡不同音源音量差异的场景。例如，在观看视频时，对话部分可能很小声，而爆炸场景则非常响亮，音量均衡器可以有效缩小这种差距。在玩游戏时，游戏内音效的动态范围可能很大，均衡器可以帮助玩家更好地听到细微的声音，同时避免被突发的巨响惊吓。此外，项目还提供了一个可选的 GTK3 GUI 界面，允许用户方便地全局或针对特定应用程序启用/禁用音量均衡功能，并调整释放时间（release time）等参数。配置信息支持通过 PipeWire 元数据对象进行持久化，方便脚本化控制。

**总结**

`pw-loudness-eq` 项目通过对 Windows 音频引擎的深入逆向工程，成功地将实用的音量均衡和输出限制功能移植到了 PipeWire 环境中。该项目不仅提供了核心的音频处理算法，还包含用户友好的配置选项和 GUI 界面，为 Linux 用户带来了更佳的音频体验。其模块化的设计和对 PipeWire API 的灵活运用，为其他音频处理插件的开发提供了借鉴。

近期，1Password 报告了一起安全事件，一名攻击者成功入侵了其部分后端系统。此次事件的根源在于攻击者利用了员工的 GitHub 账户，并借此访问了源代码，进而将恶意代码注入到后端服务中，最终窃取了部分客户的账户信息。

**技术实现与影响**

攻击者通过员工 GitHub 账户获得了对源代码的访问权限，并成功将恶意代码注入到后端服务中，导致了部分客户账户信息的泄露。受影响的信息包括客户的姓名、电子邮件地址、账户和用户标识符、账户创建和最后登录时间，以及公共密钥和安全远程密码协议参数等非敏感元数据。值得注意的是，攻击者并未能访问或获取客户的密码存储库（vaults）、密钥以及 1Password 自身不存储的账户密码和密钥。

**总结**

虽然此次事件导致了部分客户的非敏感账户信息泄露，但 1Password 的核心安全设计确保了用户密码库（vaults）及其内容的安全性并未受到影响。此次事件强调了持续的安全监控、凭证管理和供应链安全的重要性，并提醒用户保持警惕，防范潜在的网络钓鱼攻击。
